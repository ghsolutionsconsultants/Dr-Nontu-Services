# Practice photographs

Drop the practice's own photos in this folder, then point the matching entry in
`lib/content.ts → photos` at the file, e.g. `hallway: '/photos/reception.jpg'`.

JPG, landscape or portrait, at least 1600px on the long side. Natural light, uncluttered.
